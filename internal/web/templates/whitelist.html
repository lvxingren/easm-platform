批量导入白名单

导入分两步：填好后点「解析预览」核对清单，再「确认导入」写库（整表导入不会一步生效）。两种录入方式可单独或同时提交（同时提交时合并解析）：
① 文本行：每行一条 IP + 端口，多端口用逗号隔开。支持 1.2.3.4 22,80,443、1.2.3.4,22,80、1.2.3.4:3306、端口范围 10.0.0.5 1000-2000，行尾可加 udp（默认 tcp）。IP 支持单 IP / CIDR / *。
② Excel / CSV 模板：列固定为 IP/网段、端口、服务、备注（一行一条规则，端口列可写 22,80,443 或 1000-2000）；需区分 UDP 或补充维护信息时，可自行加表头列 协议、负责人、业务。首行表头自动识别，删掉表头则按上述列序解析。

白名单格式与匹配说明

字段支持写法示例
IP 规则单 IP / CIDR / *（全部）1.2.3.4　10.0.0.0/16　*
端口单端口 / 范围 / 逗号分隔 / *443　1000-2000　22,80,443
协议tcp / udp / *tcp　*

匹配逻辑：扫描完成后逐个开放端口与白名单比对，命中任意一条即放行、不告警；未命中的登记为告警并可推送飞书。IP 规则不支持 a-b 范围写法（范围仅用于资产台账），连续网段请用 CIDR。
