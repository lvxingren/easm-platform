白名单格式与匹配说明

字段支持写法示例
IP 规则单 IP / CIDR / *（全部）1.2.3.4　10.0.0.0/16　*
端口单端口 / 范围 / 逗号分隔 / *443　1000-2000　22,80,443
协议tcp / udp / *tcp　*

匹配逻辑：扫描完成后逐个开放端口与白名单比对，命中任意一条即放行、不告警；未命中的登记为告警并可推送飞书。IP 规则不支持 a-b 范围写法（范围仅用于资产台账），连续网段请用 CIDR。
